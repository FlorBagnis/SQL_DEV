## ✨ Características

- **Acceso 100% Online:** Corre de inmediato en cualquier navegador moderno sin instalaciones ni configuraciones previas.
- **12 Módulos Progresivos:** Desde consultas elementales hasta agregaciones con métricas de rentabilidad.
- **Validación Inmediata:** Feedback didáctico en tiempo real explicando el *por qué* de cada respuesta correcta o incorrecta.
- **Caso Práctico Integrado:** Tabla en vivo (`proyectos`) modelada con escenarios reales de gestión de clientes, horas estimadas vs. reales, estados y rentabilidad.
- **Diseño Kawaii Tech:** Paleta pastel cuidada, tipografía monoespaciada (`JetBrains Mono` / `Nunito`), animaciones fluidas y barra de progreso dinámica.
- **Modal Interactivo:** Sección *About* para conocer el perfil detrás del proyecto y sus objetivos técnicos.

## 📚 Temario Cubierto

| Módulo | Concepto SQL | Caso de Uso |
| :---: | :--- | :--- |
| **01** | `SELECT *` | Auditoría general y recuperación completa de registros |
| **02** | `SELECT col1, col2` | Proyección de campos específicos para reportes de horas |
| **03** | `WHERE col = 'texto'` | Filtrado exacto por nombre de cliente |
| **04** | `WHERE col > num` | Detección de proyectos con desvíos de horas reales |
| **05** | Operador `AND` | Filtros combinados obligatorios (estado + rentabilidad) |
| **06** | Operador `OR` | Filtros alternativos entre múltiples estados |
| **07** | `DISTINCT` | Deduplicación de clientes en listados |
| **08** | `ORDER BY ... DESC` | Jerarquización de proyectos por consumo de horas |
| **09** | `LIMIT` | Optimización de rendimiento y lectura controlada |
| **10** | `COUNT(*)` | Conteo de tickets/proyectos por tipo de servicio |
| **11** | `SUM(...)` | Consolidación del total de horas reales trabajadas |
| **12** | `GROUP BY` | Segmentación y métricas agrupadas por cliente |

Acá tenés una sección de Objetivos lista para sumar a tu README.md, orientada a que quien use la herramienta sume una habilidad técnica práctica y aplicable:

🎯 Objetivos del Proyecto
Incorporar SQL como herramienta de trabajo: Facilitar un primer acercamiento amigable y sin fricción técnica al lenguaje de consultas más utilizado en la industria tecnológica.

Desmitificar las bases de datos relacionales: Demostrar que interactuar con tablas, filtros y métricas no requiere conocimientos avanzados de ingeniería, sino entender la lógica detrás de los datos.

Aplicar la teoría a situaciones reales: Brindar un aprendizaje contextualizado en problemáticas cotidianas de operaciones, soporte técnico y seguimiento de proyectos en plataformas SaaS.

Fomentar la autonomía técnica: Impulsar a que perfiles no técnicos o en transición hacia el área de producto/soporte puedan explorar, diagnosticar y validar información de manera independiente.

Aprender haciendo (Hands-on): Ofrecer una experiencia interactiva donde el error forme parte del proceso gracias al feedback inmediato y explicaciones paso a paso.
