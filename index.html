💗 About the Dev & Project

¡Hola! Soy Flor Bagnis. Desarrollé este entorno interactivo con el objetivo de brindar una plataforma práctica, didáctica y completa para afianzar consultas SQL relacionales aplicadas a la operatoria SaaS y el análisis técnico de métricas.

El simulador cuenta con 36 retos interactivos distribuidos en 3 niveles de complejidad, integrando terminal de edición de código en vivo, pistas guiadas, tablas generadas al vuelo y preguntas de lógica relacional.
